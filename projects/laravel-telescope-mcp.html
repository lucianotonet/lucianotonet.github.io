lucianotonet/laravel-telescope-mcp

Pacote para conectar eventos do Laravel Telescope ao ecossistema MCP com contexto técnico reutilizável.

Laravel Telescope MCP

1) Instalação

composer require lucianotonet/laravel-telescope-mcp

2) Pré-requisitos

Laravel com Telescope ativo, acesso ao banco de telemetria e cliente MCP para consumo do servidor.

3) Inicialização

php artisan telescope-mcp:serve

4) Cenário ideal

Depuração assistida com IA em incidentes reais, correlacionando requests, exceptions e jobs em um único fluxo.
