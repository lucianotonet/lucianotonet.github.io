lucianotonet/groq-php

Biblioteca para integrar a API da Groq em PHP com uma superfície de uso simples e direta.

Composer PHP 8+ LLM

1) Instalação

composer require lucianotonet/groq-php

2) Variável de ambiente

GROQ_API_KEY=seu_token_aqui

3) Exemplo rápido

<?php
use LucianoTonet\GroqPHP\Groq;

$groq = new Groq(getenv('GROQ_API_KEY'));
$response = $groq->chat()->create([
  'model' => 'llama-3.1-8b-instant',
  'messages' => [
    ['role' => 'user', 'content' => 'Explique resumidamente este projeto.']
  ]
]);

4) Boas práticas

Armazene a chave em ambiente seguro, trate limite de requisição e registre respostas para observabilidade.
